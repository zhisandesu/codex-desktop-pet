# 柯朵桌宠 1.0：先读我

柯朵是一只住在 Windows 桌面上的小龙娘。她会走路、坐下、自己玩耍，也能在连接本机 Codex 后对任务状态作出反应。

## 三步开始

1. 完整解压 `Keduo-1.0-win-x64-portable.zip`，不要在压缩包窗口里直接运行。
2. 双击 `Start-Keduo.cmd`，或运行 `XiaobianPet.exe`。
3. 先体验角色互动；需要聊天、任务反馈或语音时，再配置自己的账号与服务。

运行环境为 Windows x64，便携包已包含 .NET 运行时。暂不提供 macOS、Linux 或手机版。未签名程序可能显示系统提示，请核对来源及 SHA256，不要关闭系统防护。

## 和她互动

| 你做什么 | 她会怎样 |
| --- | --- |
| 不按鼠标，在头部连续左右轻抚 | 触发摸头反应 |
| 长按片刻后拖动 | 按抓取位置出现不同反应 |
| 单击角色 | 弹脑门后摔倒再站起 |
| 双击角色 | 招手问候 |
| 点击旁边的小球 | 打开聊天和任务面板 |
| 右键角色 | 管理外观、语音、动态台词和记忆 |

空闲时的动作由程序调度，不保证按固定顺序出现。忙碌和重要反馈可能暂时优先于普通互动。

## 聊天和任务陪伴

自行安装并登录兼容的 Codex 桌面端/CLI。文字对话复用你自己的本机登录，模型可用性和额度取决于你的账号。可以尝试输入“柯朵，我今天把项目做完了”。

未连接时，先使用桌面动画与鼠标互动。连接功能受 Codex 版本影响，不保证所有版本都兼容。应用不附赠任何模型账号或 API 额度。

## 语音是可选项

- `Configure-Voice.cmd`：配置你自己的方舟 Agent Plan 凭据，隐藏输入并保存到本机 Windows 凭据管理器。不要把密钥发给作者或贴进 Issue。
- 没有云端凭据时，朗读可回退到本机 SAPI；云端识别并不会因此自动可用。
- `Setup-Local-ASR.cmd`：可选本地识别回退，需下载约 1.6 GB 模型及 Python 依赖。脚本针对 CUDA/GPU 路线；先检查硬件与空间，不是启动桌宠的必做步骤。
- 云端语音会把当前录音或需要朗读的文本发送给对应服务，请按自己的隐私偏好启用。

## 更新、退出与个人数据

更新前退出旧版，把新版解压到新文件夹，不要覆盖运行中的程序。个人设置和聊天数据保存在 `%LocalAppData%\XiaobianPet`，卸载程序文件不会自动删除它们，也不会删除 Windows 凭据。

可以自行备份个人数据目录，但不要把备份放进公开压缩包、Git 仓库或报错附件。本发行包不含作者的 API 凭据、登录、设置、录音或聊天记录。

## 常见问题

- **找不到程序或动画**：重新完整解压便携 ZIP，不要只复制 exe，也不要把源码 ZIP 当成安装包。
- **不能聊天**：确认本机 Codex 已登录、模型可用，再检查连接；不需要填写作者的密钥。
- **没有声音或识别失败**：先检查语音开关、系统音量、麦克风权限和自己的服务配置。本地识别属于额外安装项。
- **反馈问题**：说明 1.0 版本、Windows 版本、操作步骤和错误现象；截图遮掉隐私，不要提交完整日志、密钥、录音和聊天记录。
