# 柯朵桌宠 1.0

我将codex娘做成桌宠了。

她叫柯朵，是陪你待在 Windows 桌面上的小龙娘：可以摸头、拖拽，会走路、坐下和自己玩耍。连接本机 Codex 后，她会对任务忙碌、等待确认、完成和失败作出反馈；打开旁边的小球，也可以和她中文聊天。

## 三个压缩包

- `Keduo-1.0-win-x64-portable.zip`：给普通使用者。完整解压后运行 `Start-Keduo.cmd`；内含程序、运行时、动画、封面和说明。
- `Keduo-1.0-source.zip`：完整源码与真实动画帧，给需要阅读或构建项目的人。
- `Keduo-1.0-covers-and-guide.zip`：仅封面、功能介绍图和说明，便于单独分享。

4:3 主封面的标题为“我将codex娘做成桌宠了”，16:9 介绍图概览桌面互动、任务陪伴与中文聊天。两张图片均标注 1.0。

## 这次整理了什么

统一版本名与包名；补齐快速上手、操作方式、账号与可选语音配置、更新和隐私说明。保留发行前后敏感信息扫描、动画完整性校验、离线测试、ZIP CRC 与 SHA256 检查。

## 使用边界

Windows x64；不是 OpenAI 官方产品。程序不附带作者的 API Key、账号、个人配置或聊天记录，也不附赠模型额度。Codex 和云端语音需使用者自行配置；可选本地识别模型不随包提供。

本版未签名、无在线自动更新器，代码和角色素材尚未指定开源或再分发许可证。真实账号连接、语音效果和干净机器启动仍需按实际环境验收。版本名变更不代表新增功能或完成了全环境测试。
