# 柯朵 · Codex 小龙桌宠

柯朵是陪主人使用 Codex 的 Windows WPF 小龙桌宠。她用 `gpt-5.6-luna` 生成中文对白，用方舟“调皮公主 · 微沙奶幼”音色朗读，并把主人直接说过的重要信息整理成长期记忆。

文字对话通过本机 `codex app-server --stdio` 复用已登录的 ChatGPT/Codex 账号。程序不读取 `OPENAI_API_KEY`，也不调用 OpenAI Platform API。

## 直接使用

双击工作区根目录的 `启动柯朵.cmd`。如果她已经在后台运行，启动器会把她移回主屏幕右下角并展开面板。原来的“启动小编龙”脚本仍可兼容使用。

- 摸头：不按鼠标，在角色头部连续左右轻抚。单次划过不触发；离开头部、停顿或按下鼠标会清空手势。触发后冷却 9 秒，不能抢占抓取、弹脑门、生气或忙碌桌前循环。
- 长按角色片刻再拖动：按住满 300 毫秒且移动超过系统拖拽距离后，按最初点击的位置触发抓头、抓翅膀或抓身体。抓点跟随光标，松手直接进入原有生气反馈或待机；软着陆、额外下移缓动及软着陆预览已停用，原视频只保留作归档。
- 单击角色：弹脑门后摔倒再站起来；聊天面板由旁边的悬浮球打开
- 双击角色：招手并问候
- 右键角色：管理语音、动态台词、长期记忆和方舟音色；“外观设置”里可调整透明度，并用开发预览按钮让角色原地播放任一正式动画
- 面板“回复”页：查看当前回复和最近 40 条本地聊天备份
- 面板“开始语音”：连续进行半双工语音聊天

空闲时她会随机左右行走、向任一可用方向奔跑摔倒、贴着屏幕向上攀爬或向下跳落。普通左右走路每次固定播放四个完整八帧循环（共 5.824 秒），设置页预览也使用相同四轮长度；跑摔是从站姿边界直接开始的独立一次性动作，不再由走路衔接。左右行走使用分别生成的角色朝向素材；左向跑摔按用户要求逐帧镜像右向完整 193 帧且不反转帧序；攀爬和跳落会播放完整正向动作并同步移动窗口，不使用倒放或乒乓循环。

空闲坐姿会依次经过坐下、完整盘腿待机、随机不重复的歪头/眨眼/捂头/托腮摇头手势，再完整站起。任务状态、临时反馈、设置预览和空闲行为等普通切换，会等当前一次性动画播到末帧或循环动画回环后再开始；坐姿会先自然站起。确认后的单击、双击和真正开始的抓取会立即抢占当前画面；单击反应本身仍会完整播放，只有抓取可以打断。

任务进度、等待确认、完成和失败仍会触发角色反馈。点击、拖拽和任务状态使用独立的临时 Luna 线程，不会污染她和主人的长期房间，也不会被桌面任务监控再次触发。

## 任务情境反馈

右键“任务情境反馈”可开关此功能，默认开启。她复用已有的 Codex 任务监听，在本地识别当前执行轮次的用户消息与文件改动，不额外拉取完整历史。角色自己的台词房间不参与统计。

- 新一轮消息以“继续”“接着”等开头且任务确实在运行：例如“收到，这就继续帮你执行！”
- 当前轮次出现代码文件改动：等约 20 秒，偶尔说“呜，这些屎山代码太难修了，让我一块块拆！”等台词。这是角色的夸张吐槽，不是代码质量评估。

每轮每类只反馈一次，两句至少间隔 25 秒，代码吐槽至少间隔 2 分钟。启动、重连、启用开关不会补播旧记录；任务已结束或提示过时就丢弃。抓取、生气、直接对话及重要播报优先，任务气泡不会在说话中被普通进度刷新立刻盖掉。

这些台词使用本地短句，经已有语音服务朗读；不把任务标题、正文、源码、补丁或日志发送给台词模型，也不写入角色记忆。关闭语音后仍显示气泡。此功能只对 Codex 任务作出反应，不监听其他编辑器、不自动执行或继续任务。

## 柯朵的房间

文字和语音直接聊天共用原来的持久 Codex 会话，显示标题更新为“柯朵的房间”。程序会在重启后恢复同一个会话，并固定使用 `gpt-5.6-luna`、ChatGPT 登录、OpenAI provider、只读沙箱和禁用工具模式；任何关键条件不符都会停用动态对白并回到本地台词。

用以下称呼开头即可和她聊天：

```text
柯朵
小编龙（旧称兼容）
编编
小龙
```

例如：

```text
柯朵，我今天终于把短片做完了
柯朵，你还记得我喜欢喝什么吗
```

普通 Codex 任务仍在面板中单独管理。若内容以角色称呼开头，但你想强制发给当前 Codex 任务，可使用：

```text
/codex 柯朵这个名字出现在哪些文件里
```

## 性格和角色设定

默认性格是奶声奶气的小女孩感：可爱软萌、稍微害羞、偶尔天然呆，再带一点嘴硬心软的轻傲娇。她只在自然时称呼对方为“主人”，不会使用客服腔、括号动作、emoji 或堆叠语气词。

主人可以追加长期角色设定：

```text
柯朵，设定：回答时再害羞一点
柯朵，查看设定
柯朵，恢复默认设定
柯朵，确认恢复默认设定
```

设定最多 12 条，每条最多 120 个字。恢复默认设定必须在 30 秒内用键盘二次确认。

## 常驻房间与长期记忆

柯朵的主要记忆直接保留在常驻 Codex 房间中，由房间上下文承接并在变长后压缩。程序不会在每次聊天时重复发送整份本地记忆；只在启动后首次使用或切换到新房间时恢复一次本地重点索引，明确查询时只发送命中的少量条目。

开启右键菜单中的“本地重点备份（房间记忆为主）”后，Luna 可从主人直接聊天的当前一句话中提出最多两个高置信度候选，供查看、定向遗忘和新房间恢复。程序还会独立检查：

- 引文必须逐字出现在主人当前输入中
- 保存内容只能由这段引文确定，模型不能夹带新事实
- 只接受稳定的偏好、讨厌、习惯、目标、关系、个人资料和重要事件
- 疑问、假设、玩笑、短暂情绪、第三方信息和敏感凭据不保存
- 自动更新只能修改同类别、同主题的自动记忆，不能覆盖主人明确写入的记忆

点击、拖拽、任务内容、文件、命令输出和环境台词不会进入本地重点索引。索引最多 120 条，每条最多 80 个字；关闭索引不会重置常驻房间。

主人也可以直接管理记忆：

```text
柯朵，记住：我喜欢无糖拿铁
柯朵，你记得什么
柯朵，忘掉：无糖拿铁
柯朵，清空记忆
柯朵，确认清空记忆
```

删除、清空和恢复默认设定只接受键盘输入，避免语音误识别造成破坏。忘记或清空时，程序会先持久化旧会话的退役标记并切换本地上下文，再修改本地索引；剩余索引会在新房间首次聊天时恢复一次。断网或进程中断也不会让旧房间在重启后重新成为活动会话。

本地加密聊天备份会继续保留供主人查看，但旧代际内容不会再次发送给 Luna。这里的“忘记”表示从活动长期记忆和后续模型上下文中移除，不表示物理抹除所有本地备份。

## 本地数据

数据位于 `%LocalAppData%\XiaobianPet`：

```text
settings.json                         窗口、语音和授权设置
memory.json                           结构化长期记忆，本机明文 JSON
character-profile.json                主人追加的角色设定，本机明文 JSON
dialogue-session.json                 活动会话及退役墓碑
conversation-context.json             本地聊天上下文代际
conversation-history.dpapi.jsonl      Windows 当前用户 DPAPI 加密的聊天备份
startup-error.log                     启动与运行错误
```

对话备份逐条加密，不保存原始音频。密码、Token、API Key 和私钥会被记忆系统拒绝。损坏或未知版本的记忆文件会进入保护状态，避免静默覆盖；合法的 120 条满容量中文记忆已按实际序列化大小验证。

## 语音聊天

语音链路为：

```text
麦克风 → 豆包 Seed-ASR 2.0 → 文本 → 柯朵的 Luna 房间 → 方舟 TTS
                         ↘ 失败时使用本机 Whisper
```

Agent Plan ASR 是默认识别后端。它把当前一句 16 kHz 单声道 WAV 上传到方舟语音识别服务；识别文字才会进入 Luna，原始录音不会发送给 OpenAI 或 Codex。云端失败或超时时，程序使用本机 Whisper large-v3-turbo 重新识别，并在收音期间提前预热本地模型以缩短回退等待。

录音写入 `%LocalAppData%\XiaobianPet\VoiceTemp`。每轮结束会多次重试删除；意外残留会在下次启动时清理一小时前的临时文件。

当前模式是连续半双工：主人说完并停顿约一秒，程序识别、思考、朗读，随后继续监听。它没有 ChatGPT Realtime Voice 的全双工回声消除、边听边说和随时插话能力。`gpt-5.6-luna` 本身只处理文本，不原生接收音频。

## 方舟配置

首次使用双击：

```text
配置柯朵方舟语音.cmd
```

脚本用 `SecureString` 接收 Agent Plan API Key，并保存到 Windows Credential Manager：

```text
XiaobianPet/ArkAgentPlanTts
```

同一凭据用于 Agent Plan ASR 和 TTS，不会写入 `settings.json`。默认 TTS 音色为“调皮公主 · 微沙奶幼”；右键菜单还可切换并试听其他方舟音色。方舟不可用时，朗读会回退到 Windows SAPI。

本机 Whisper 是可选回退。首次配置双击：

```text
配置柯朵本地语音识别.cmd
```

约 1.6 GB 的模型保存在：

```text
%LocalAppData%\XiaobianPet\Models\faster-whisper-large-v3-turbo
```

## 用量和费用边界

- Luna 文字回复占用当前 ChatGPT/Codex 套餐包含的使用量
- 程序不会调用 OpenAI Platform API，因此不会由本程序产生 Platform API 按量账单
- Agent Plan ASR 和 TTS 使用方舟 Agent Plan 的燃料或套餐额度
- 本机 Whisper 不消耗云端模型额度

若 ChatGPT/Codex 套餐用量耗尽，动态对白会回到本地词库。账号已有的 ChatGPT credits 如何消耗，仍以账号当时的套餐规则为准。

## 开发与打包

需要 .NET 9 Windows Desktop Runtime。

```powershell
dotnet build .\XiaobianPet.csproj
dotnet publish .\XiaobianPet.csproj -c Release -r win-x64 --self-contained false -o .\dist
```

角色运行资源只读取 `Assets/animations` 中的视频生成拆帧，不再包含混合旧图生动作的 `spritesheet.png`。待机、眨眼待机、左右行走、双向跑摔、三种抓取、攀爬和下跳均使用独立序列；尚未制作视频版本的招手、普通跳跃和任务状态暂时统一显示视频待机，避免切回旧图生素材造成色跳。
