# 柯朵桌宠 · 首次预览版

我把 Codex 娘做成了 Windows 桌宠。

她叫柯朵：可以摸头、拎起来，也会自己走路、坐下和玩耍。连接本机 Codex 后，她会对任务忙碌、等待确认、完成和失败作出反应；打开旁边的小球，还可以和她中文聊天。

## 下载哪个

- **普通使用者**：下载 `Keduo-0.1.0-preview.1-win-x64-portable.zip`，完整解压后双击 `Start-Keduo.cmd`。包含 .NET 运行时，不需单独安装；仅限 Windows x64。
- **查看或构建代码**：下载 `Keduo-0.1.0-preview.1-source.zip`，或克隆仓库后执行 `git lfs pull`。自带源码 ZIP 已包含真实动画帧。
- `SHA256SUMS.txt` 是压缩包校验值；`release-audit.json` 是便携包文件清单。

便携包约 632 MiB，源码包约 563 MiB。主要体积来自 4,740 张正式动画帧。

## 本版内容

- 角色鼠标互动、自主游戏、坐姿与移动动画。
- Codex 任务状态和情境反馈，中文聊天、角色设定及本地重点记忆管理。
- 可选云端语音与本机回退；需要使用者自行配置账号、凭据或模型。
- 发行前后敏感信息扫描、动画完整性检查、8 组离线回归、ZIP CRC 和 SHA256 校验。

## 使用前请了解

这是个人社区项目，不是 OpenAI 官方产品。下载包不含开发者的 API Key、账号登录、聊天记录或个人配置，也不附赠模型额度。

本版未签名、没有自动更新器；更新时退出旧版并解压到新目录。个人数据位于 `%LocalAppData%\XiaobianPet`，不要将该目录上传仓库或用于公开报错。

干净机器启动验收、真实账号连接和语音体验仍需按自己的环境验证。代码与角色素材尚未指定开源或再分发许可证，详见仓库授权状态说明。

后续会继续完善交互、兼容性和配置体验。反馈问题时请说明版本、系统和复现步骤，不要附带密钥、录音或完整聊天记录。
